Vanguard Team — نسخه شخصی

این پروژه یک اپلیکیشن مستقل برای مدیریت مجموعه شخصی هر کاربر است.
اطلاعات در حافظه محلی همان دستگاه ذخیره می‌شود و بین کاربران یا گوشی‌ها به اشتراک گذاشته نمی‌شود.

امکانات نسخه شروع:
- مدیریت اعضا و مشخصات آن‌ها
- پرونده هر عضو و چک‌لیست رشد اختصاصی
- افزودن، ویرایش، حذف و جابه‌جایی مراحل چک‌لیست
- افزودن، ویرایش، حذف و تکمیل وظایف
- ساختار درختی مجموعه
- خروجی و بازیابی فایل پشتیبان

ساخت APK:
1) Node.js و Android Studio را نصب کنید.
2) در پوشه پروژه اجرا کنید: npm install
3) اجرا کنید: npx cap add android
4) اجرا کنید: npx cap sync android
5) اجرا کنید: npx cap open android
6) در Android Studio از منوی Build گزینه Build APK(s) را انتخاب کنید.

نکته: این خروجی ZIP سورس پروژه آماده ساخت است، نه فایل APK نهایی. APK باید با Android SDK/JDK ساخته و روی دستگاه واقعی تست شود.
